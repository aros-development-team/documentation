ChangeLog-AROS:
    Wijzigingen log (ChangeLog) voor de AROS core broncode.
ChangeLog-contrib:
    Wijzigingen log (ChangeLog) voor de broncode van gecontributeerde
    programma's.
ChangeLog-docs:
    Wijzigingen log (ChangeLog) voor de documentatie
source:
    Broncode AROS core.
docs-source:
    Broncode (Engelstalig) documentatie.
contrib-source:
    Broncode gecontributeerde programma's.
docs-html:
    Engelstalig documentatie in HTML formaat. Bevat alle documentatie
    die op de website staat, maar nu aangepast voor het offline lezen.
freebsd5-i386-system:
    De gehoste versie voor FreeBSD/i386 5.x. Deze werkt overigens
    niet onder FreeBSD 4.x systemen.
freebsd-i386-system:
    De gehoste versie voor FreeBSD/i386 5.x. Deze werkt niet onder
    FreeBSD 4.x systemen.
linux-i386-system:
    De gehoste versie voor Linux/i386. Dit is de meest complete en
    capabele versie, wat betekend dat je hiermee alle bijgesloten
    programma's en demo's kunt draaien. Dit archief bevat ook alle AROS
    systeem binaries gecompileerd vanuit de Subversion tak. 
mingw32-x86_64-system:
    De gehoste versie voor Microsoft Windows op het x86_64 platform.
mingw32-i386-system:
    De gehoste versie voor Microsoft Windows op het i386 platform.
    Ontwikkeld en gecompileerd onder Windows XP, maar zou moeten werken
    op alle 32-bit Windows versies vanaf Windows 98.
linux-x86_64-system:
    De gehoste versie voor Linux/x86_64. Dit is de meest complete en
    capabele versie, wat betekend dat je hiermee alle bijgesloten
    programma's en demo's kunt draaien. Dit archief bevat ook alle AROS
    systeem binaries gecompileerd vanuit de Subversion tak. 
linux-ppc-system:
    De gehoste versie voor Linux/PowerPC. Dit archief bevat alle AROS
    systeem binaries gecompileerd vanuit de Subversion tak.
pc-i386-boot-floppy:
    De native versie voor i368-gebaseerde PC AT compatibele
    computers. Dit archief bevat de boot floppy disk image, welke naar een
    schijf te schrijven is om AROS mee te starten. 
pc-i386-boot-iso:
    De native versie voor i386-gebaseerde PC AT compatibele computers.
    Dit is een opstartbaar CDROM ISO bestand, dat alle AROS systeem en
    gecontribueerde programma's bevat.
raspi-aarch64-system:
    De native versie voor ARMv8-gebaseerde 64bit Raspberry Pi
    computers. Bevat alle bestanden die nodig zijn om op te starten
    vanaf een FAT-geformatteerde sd-kaart.
raspi-aarch64-contrib:
    Dit archief bevat alle gecontribueerde programma's gecompileerd
    voor de ARMv8 64bit architectuur, voor gebruik met de
    RasPi/aarch64 port.
raspi-aarch64-ports:
    Dit archief bevat applicaties en spellen die gebouwd zijn vanuit
    externe bronnen voor de ARMv8 64bit architectuur (zowel gehost
    als native). Vanwege de grootte zal het archief slechts af en toe
    worden bijgewerkt op de snapshots pagina.
raspi-armhf-system:
    De native versie voor ARMv6-gebaseerde Raspberry Pi computers.
    Bevat alle bestanden die nodig zijn om op te starten vanaf een
    FAT-geformatteerde sd-kaart.
raspi-armhf-contrib:
    Dit archief bevat alle gecontribueerde programma's gecompileerd
    voor de ARM architectuur, voor gebruik met de RasPi/ARM port
    (met hard-float ABI). Let op: deze versie vereist minimaal een
    ARMv6 CPU met VFP eenheid.
raspi-armhf-ports:
    Dit archief bevat applicaties en spellen die gebouwd zijn vanuit
    externe bronnen voor de armhf architectuur (zowel gehost als
    native). Vanwege de grootte zal het archief slechts af en toe
    worden bijgewerkt op de snapshots pagina.
pc-i386-contrib:
    Dit archief bevat alle gecontribueerde programma's gecompileerd voor
    de i386 architectuur. Deze werken zowel in de gehoste (bijv. i386-linux)
    als native (i386-pc) versies. 
pc-x86_64-boot-iso:
    De native versie voor 64-bit (x86_64, amd64) PC computers. Dit omvat een
    opstartbare CD-ROM ISO image, welke alle AROS systeem en contributie
    programmatuur bevat.
pc-x86_64-smp-boot-iso:
    Dit is een zeer experimentele SMP versie voor pc-x86_64.
    Alleen aanbevolen voor ontwikkelaars. Dit is een opstartbare
    CD-ROM ISO image.
pc-x86_64-contrib:
    Dit archief bevat alle gecontribueerde programma's gecompileerd
    voor de x86_64 architectuur, voor gebruik met de x86_64 native
    versie.
linux-ppc-contrib:
    Dit archief bevat alle gecontribueerde programma's gecompileerd voor
    de PowerPC architectuur, voor gebruik met Linux/PowerPC port.
pc-i386-sdk:
    Een set van bestanden en tools waarmee u eigen AROS programma's kunt
    bouwen op een machine naar uw keuze. Benodigd zijn ook gcc en binutils,
    beiden geconfigureerd voor het produceren van i386-elf executables.
linux-ppc-sdk:
    Een set van bestanden en tools waarmee u eigen AROS programma's kunt
    bouwen op een machine naar uw keuze. Benodigd zijn ook gcc en binutils,
    beiden geconfigureerd voor het produceren van ppc-elf executables.
pc-x86_64-sdk:
    Een set van bestanden en tools waarmee u eigen AROS programma's kunt
    bouwen op een machine naar uw keuze. Benodigd zijn ook gcc en binutils,
    beiden geconfigureerd voor het produceren van x86_64-elf executables.
