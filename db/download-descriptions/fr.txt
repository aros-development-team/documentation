freebsd5-i386-system:
    Version hôte pour FreeBSD/i386 5.x. Elle ne fonctionnera
    pas sur FreeBSD 4.x.
freebsd-i386-system:
    Version hôte pour FreeBSD/i386 5.x. Elle ne fonctionnera
    pas sur FreeBSD 4.x.
linux-i386-system:
    La version hôste pour Linux/i386. C'est la version la plus
    complète, ce qui signifie que vous pouvez démarrer tous les
    programmes et démos inclus avec. Cette archive contient tous
    les fichiers binaires compilés depuis SVN.
mingw32-x86_64-system:
    La version hôte pour Microsoft Windows sur la plateforme x86_64.
mingw32-i386-system:
    La version hôte pour Microsoft Windows sur la plateforme i386.
    Développée et compilée sous Windows XP, elle devrait toutefois
    fonctionner sur toutes les versions 32 bits de Windows à partir
    de Windows 98.
linux-x86_64-system:
    La version hôste pour Linux/x86_64. C'est la version la plus
    complète, ce qui signifie que vous pouvez démarrer tous les
    programmes et démos inclus avec. Cette archive contient tous
    les fichiers binaires compilés depuis SVN.
linux-ppc-system:
    La version hôste pour Linux/PowerPC. Cette archive contient tous
    les fichiers binaires compilés depuis SVN.
pc-i386-boot-floppy:
    La version native pour PC avec processeur i386 et
    compatibles. Cette archive contient l'image d'une disquette
    à partir de laquelle on peut démarrer AROS.
pc-i386-boot-iso:
    La version native pour PC avec processeur i386 et
    compatibles. Cette archive contient l'image du CDROM bootable,
    ainsi que tous les programmes de contribution.
pc-x86_64-boot-iso:
    La version native pour PC avec processeur x86_64.
    Cette archive contient l'image du CDROM bootable,
    ainsi que tous les programmes de contribution.
pc-x86_64-smp-boot-iso:
    Ceci est une version SMP hautement expérimentale pour pc-x86_64.
    Recommandée uniquement aux développeurs. Il s'agit d'une image
    ISO de CD-ROM bootable.
raspi-aarch64-system:
    La version native pour les ordinateurs Raspberry Pi 64 bits à
    base d'ARMv8. Contient tous les fichiers nécessaires pour
    démarrer depuis une carte sd formatée en FAT.
raspi-aarch64-contrib:
    Cette archive contient tous les programmes de contribution
    compilés pour l'architecture ARMv8 64 bits, à utiliser avec
    le portage RasPi/aarch64.
raspi-aarch64-ports:
    Cette archive contient des applications et des jeux compilés à
    partir de sources externes pour l'architecture ARMv8 64 bits
    (versions hôtes et natives). En raison de sa taille, l'archive ne
    sera mise à jour que de temps en temps sur la page des snapshots.
raspi-armhf-system:
    La version native pour les ordinateurs Raspberry Pi à base
    d'ARMv6. Contient tous les fichiers nécessaires pour démarrer
    depuis une carte sd formatée en FAT.
raspi-armhf-contrib:
    Cette archive contient tous les programmes de contribution
    compilés pour l'architecture ARM, à utiliser avec le portage
    RasPi/ARM (utilisant l'ABI hard-float). Notez que cette version
    nécessite au minimum un processeur ARMv6 avec unité VFP.
raspi-armhf-ports:
    Cette archive contient des applications et des jeux compilés à
    partir de sources externes pour l'architecture armhf (versions
    hôtes et natives). En raison de sa taille, l'archive ne sera mise
    à jour que de temps en temps sur la page des snapshots.
opensbi-riscv-system:
    La version native pour les systèmes UEFI OpenSBI à base de
    RISC-V 32 bits, ciblant le profil applicatif RVA22. Notez que
    cette version nécessite l'extension Zifencei.
    Actuellement, seul le Milk-V Titan est pris en charge.
opensbi-riscv-contrib:
    Cette archive contient tous les programmes de contribution
    compilés pour l'architecture RISC-V 32 bits (profil RVA22),
    à utiliser avec le portage OpenSBI/riscv.
opensbi-riscv64-system:
    La version native pour les systèmes UEFI OpenSBI à base de
    RISC-V 64 bits, ciblant le profil applicatif RVA22. Notez que
    cette version nécessite l'extension Zifencei.
    Actuellement, seul le Milk-V Titan est pris en charge.
opensbi-riscv64-contrib:
    Cette archive contient tous les programmes de contribution
    compilés pour l'architecture RISC-V 64 bits (profil RVA22),
    à utiliser avec le portage OpenSBI/riscv64.
pc-i386-contrib:
    Cette archive contient tous les programmes de contribution
    compilés pour l'architecture i386. Ils fonctionneront à la fois
    dans les versions hôtes et natives.
pc-x86_64-contrib:
    Cette archive contient tous les programmes de contribution
    compilés pour l'architecture x86_64. Ils fonctionneront à la fois
    dans les versions hôtes et natives.
linux-ppc-contrib:
    Cette archive contient tous les programmes de contribution
    compilés pour l'architecture PowerPC.
pc-i386-sdk:
    Jeu de fichiers et d'outils visant à développer vos programmes
    pour AROS avec votre machine préférée. Vous aurez également
    besoin de gcc et des binutils configurés pour produire des
    exécutables i386-elf.
linux-ppc-sdk:
