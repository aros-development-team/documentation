    Núcleo de fontes AROS.
docs-source:
    Fontes de documentação.

    Fontes de programas contribuídos.
docs-html:
    Documentação em formato HTML. Contém o que está disponível
     no Portal, mas adaptado para leitura sem ligação.
freebsd5-i386-system:
    A versão hospedada para FreeBSD/i386 5.x. Note que não
    irá funcionar em sistemas FreeBSD 4.x.
freebsd-i386-system:
    A versão hospedada para FreeBSD/i386 5.x. Note que não
    irá funcionar em sistemas FreeBSD 4.x.
linux-i386-system:
    A versão hospedada para Linux/i386. Este é o mais
    completo e maturo porto, que significa que pode correr
    todos os programas incluídos e demos com ele. Este arquivo
    contém todo o sistema de binários AROS compilados a partir da
    árvore de Subversão.
mingw32-x86_64-system:
    A versão hospedada para Microsoft Windows na plataforma x86_64.
mingw32-i386-system:
    A versão hospedada para Microsoft Windows na plataforma i386.
    Desenvolvida e compilada sob Windows XP, mas deverá funcionar em
    todas as versões de Windows de 32 bits a partir do Windows 98.
linux-x86_64-system:
    A versão hospedada para Linux/x86_64. Este é o mais
    completo e maturo porto, que significa que pode correr
    todos os programas incluídos e demos com ele. Este arquivo
    contém todo o sistema de binários AROS compilados a partir da
    árvore de Subversão.
linux-ppc-system:
    A versão hospedada para Linux/PowerPC. Este arquivo contém todo
    o sistema de binários AROS compilados a partir da árvore de Subversão.
pc-i386-boot-floppy:
    A versão nativa para Computadores PC-AT baseadas em i386 e
    compativeis. Este arquivo contém o a imagem de arranque para
    disquete no qual poderá escrever rápidamente para o disco e
    Arrancar o AROS.
pc-i386-boot-iso:
    A versão nativa para Computadores PC-AT baseados em i386 e
    compativeis. Este é a imagem ISO para arranque em CD-ROM, que
    contém todo o sistema AROS e programas contribuídos.
pc-x86_64-boot-iso:
    A versão nativa para computadores PC de 64 bits (x86_64, amd64).
    Este é a imagem ISO para arranque em CD-ROM, que contém todo o
    sistema AROS e programas contribuídos.
pc-x86_64-smp-boot-iso:
    Esta é uma construção SMP altamente experimental para pc-x86_64.
    Recomendada apenas para programadores. Este é a imagem ISO para
    arranque em CD-ROM.
raspi-aarch64-system:
    A versão nativa para computadores Raspberry Pi de 64 bits
    baseados em ARMv8. Contém todos os ficheiros necessários para
    arrancar a partir de um cartão sd formatado em FAT.
raspi-aarch64-contrib:
    Este arquivo contém todo o programa contribuído compilado
    para a arquitectura ARMv8 de 64 bits, para uso com o porto
    RasPi/aarch64.
raspi-aarch64-ports:
    Este arquivo contém aplicações e jogos construídos a partir de
    fontes externas para a arquitectura ARMv8 de 64 bits (tanto
    hospedada como nativa). Devido ao seu tamanho, o arquivo será
    actualizado apenas de tempos a tempos na página de snapshots.
raspi-armhf-system:
    A versão nativa para computadores Raspberry Pi baseados em ARMv6.
    Contém todos os ficheiros necessários para arrancar a partir de
    um cartão sd formatado em FAT.
raspi-armhf-contrib:
    Este arquivo contém todo o programa contribuído compilado para
    a arquitectura ARM, para uso com o porto RasPi/ARM (usando a
    ABI hard-float). Note que esta versão requer pelo menos uma
    CPU ARMv6 com unidade VFP.
raspi-armhf-ports:
    Este arquivo contém aplicações e jogos construídos a partir de
    fontes externas para a arquitectura armhf (tanto hospedada como
    nativa). Devido ao seu tamanho, o arquivo será actualizado
    apenas de tempos a tempos na página de snapshots.
opensbi-riscv-system:
    A versão nativa para sistemas UEFI OpenSBI baseados em RISC-V
    de 32 bits, visando o perfil de aplicação RVA22. Note que esta
    versão requer a extensão Zifencei.
    Actualmente apenas o Milk-V Titan é suportado.
opensbi-riscv-contrib:
    Este arquivo contém todo o programa contribuído compilado
    para a arquitectura RISC-V de 32 bits (perfil RVA22), para uso
    com o porto OpenSBI/riscv.
opensbi-riscv64-system:
    A versão nativa para sistemas UEFI OpenSBI baseados em RISC-V
    de 64 bits, visando o perfil de aplicação RVA22. Note que esta
    versão requer a extensão Zifencei.
    Actualmente apenas o Milk-V Titan é suportado.
opensbi-riscv64-contrib:
    Este arquivo contém todo o programa contribuído compilado
    para a arquitectura RISC-V de 64 bits (perfil RVA22), para uso
    com o porto OpenSBI/riscv64.
pc-i386-contrib:
    Este arquivo contém todo o programa contribuído
    compilado para a arquitectura i386. Eles irão funcionar em
    ambos os apropriados hospedeiros (eg. i386-linux) e versão
    nativo (i386-pc).
pc-x86_64-contrib:
    Este arquivo contém todo o programa contribuído compilado
    para a arquitectura x86_64, para uso com a versão nativa
    x86_64.
linux-ppc-contrib:
    Este arquivo contém todo o programa contribuído
    compilado para a arquitectura PowerPC, para uso com o porto
    Linux/PowerPC.
pc-i386-sdk:
    Conjunto de ficheiros e ferramentas para construir os seus
    programas AROS na sua máquina preferida. Irá precisar também do gcc e o
    binutils configurados para produzir executáveis i386-elf.
linux-ppc-sdk:
    Conjunto de ficheiros e ferramentas para construir os seus
    programas AROS na sua máquina preferida. Irá precisar também do gcc e o
    binutils configurados para produzir executáveis ppc-elf.
pc-x86_64-sdk:
    Conjunto de ficheiros e ferramentas para construir os seus
    programas AROS na sua máquina preferida. Irá precisar também do gcc e o
    binutils configurados para produzir executáveis x86_64-elf.
