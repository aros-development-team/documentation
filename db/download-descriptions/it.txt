ChangeLog-docs:
    Modifiche alla documentazione.
source:
    Sorgenti principali di AROS.
docs-source:
    Sorgenti della documentazione.
contrib-source:
    Sorgenti dei programmi scritti da terzi.
docs-html:
    Documentazione in HTML. Contiene tutto quello che c'è
    scritto nel sito, ma adattato per la lettura offline.
freebsd5-i386-system:
    Versione hosted per FreeBSD/i386 5.x. Non funziona
    su sistemi FreeBSD 4.x.
freebsd-i386-system:
    Versione hosted per FreeBSD/i386 5.x. Non funziona
    su sistemi FreeBSD 4.x.
linux-i386-system:
    La versione hosted per Linux/i386. Questo archivio
    contiene tutti i file di sistema compilati
    dall'albero di SVN.
mingw32-x86_64-system:
    La versione hosted per Microsoft Windows su piattaforma x86_64.
mingw32-i386-system:
    La versione hosted per Microsoft Windows su piattaforma i386.
    Sviluppata e compilata sotto Windows XP, ma dovrebbe funzionare
    su tutte le versioni di Windows a 32 bit a partire da Windows 98.
linux-x86_64-system:
    La versione hosted per Linux/x86_64. Questo archivio contiene
    tutti i file di sistema di AROS compilati dall'albero di SVN.
linux-ppc-system:
    La versione hosted per Linux/PowerPC. Questo archivio
    contiene tutti i file di sistema compilati dall'albero di SVN.
pc-i386-boot-floppy:
    La versione nativa per PC con processori i386 e
    compatibili. Questo archivio contiene l'immagine
    del floppy di avvio, con cui potrete realizzare un
    disco per caricare AROS.
pc-i386-boot-iso:
    La versione nativa per PC con processori i386 e
    compatibili. Questo archivio contiene l'immagine
    di un CDROM di avvio, senza software aggiuntivo.
pc-x86_64-boot-iso:
    La versione nativa per i sistemi PC a 64 bit(x86_64, amd64).
    Questa è la ISO di un CD-ROM con cui è possibile avviare il
    sistema operativo e contiene il software scritto da terzi.
pc-x86_64-smp-boot-iso:
    Questa è una build SMP altamente sperimentale per pc-x86_64.
    Consigliata solo agli sviluppatori. Questa è la ISO di un
    CD-ROM di avvio.
raspi-aarch64-system:
    La versione nativa per i computer Raspberry Pi a 64 bit basati
    su ARMv8. Contiene tutti i file necessari per l'avvio da una
    scheda sd formattata FAT.
raspi-aarch64-contrib:
    Questo archivio contiene tutto il software scritto da terzi,
    compilato per l'architettura ARMv8 a 64 bit, da usare con il
    porting RasPi/aarch64.
raspi-aarch64-ports:
    Questo archivio contiene applicazioni e giochi compilati da
    sorgenti esterni per l'architettura ARMv8 a 64 bit (sia hosted
    che nativa). A causa delle sue dimensioni, l'archivio verrà
    aggiornato solo di tanto in tanto nella pagina degli snapshot.
raspi-armhf-system:
    La versione nativa per i computer Raspberry Pi basati su ARMv6.
    Contiene tutti i file necessari per l'avvio da una scheda sd
    formattata FAT.
raspi-armhf-contrib:
    Questo archivio contiene tutto il software scritto da terzi,
    compilato per l'architettura ARM, da usare con il porting
    RasPi/ARM (con ABI hard-float). Notare che questa versione
    richiede almeno una CPU ARMv6 con unità VFP.
raspi-armhf-ports:
    Questo archivio contiene applicazioni e giochi compilati da
    sorgenti esterni per l'architettura armhf (sia hosted che
    nativa). A causa delle sue dimensioni, l'archivio verrà
    aggiornato solo di tanto in tanto nella pagina degli snapshot.
opensbi-riscv-system:
    La versione nativa per i sistemi UEFI OpenSBI basati su RISC-V
    a 32 bit, destinata al profilo applicativo RVA22.
    Attualmente è supportato solo il Milk-V Titan.
opensbi-riscv-contrib:
    Questo archivio contiene tutto il software scritto da terzi,
    compilato per l'architettura RISC-V a 32 bit (profilo RVA22),
    da usare con il porting OpenSBI/riscv.
opensbi-riscv64-system:
    La versione nativa per i sistemi UEFI OpenSBI basati su RISC-V
    a 64 bit, destinata al profilo applicativo RVA22.
    Attualmente è supportato solo il Milk-V Titan.
opensbi-riscv64-contrib:
    Questo archivio contiene tutto il software scritto da terzi,
    compilato per l'architettura RISC-V a 64 bit (profilo RVA22),
    da usare con il porting OpenSBI/riscv64.
pc-i386-contrib:
    Questo archivio contiene tutto il software scritto da
    terzi e compilato per architettura i386. funziona
    su entrambe le versioni appropriate (es. i386-linux, 
    i386-pc), siano essere hosted o native.
pc-x86_64-contrib:
    Questo archivio contiene tutto il software scritto da terzi
    compilato per l'architettura x86_64, da usare con la versione
    nativa x86_64.
linux-ppc-contrib:
    Questo archivio contiene tutti i programmi realizzati da terzi,
    compilati per l'architettura PowerPC, da usare con il porting
    per Linux/PowerPC.
pc-i386-sdk:
    Set di strumenti per compilare i vostri programmi per
    AROS, sulla macchina che preferite. Avrete bisogno di gcc
    e di binutils configurati per produrre eseguibili i386-elf.
linux-ppc-sdk:
    Set di strumenti per compilare i vostri programmi per
    AROS, sulla macchina che preferite. Avrete bisogno di gcc
    e di binutils configurati per produrre eseguibili ppc-elf.
pc-x86_64-sdk:
    Set di strumenti per compilare i vostri programmi per
    AROS, sulla macchina che preferite. Avrete bisogno di gcc
    e di binutils configurati per produrre eseguibili x86_64-elf.
