freebsd5-i386-system:
    Hostad version för FreeBSD/i386 5.x. Notera att det inte
    kommer att fungera på FreeBSD 4.x-system.
freebsd-i386-system:
    Hostad version för FreeBSD/i386 5.x. Notera att det inte
    kommer att fungera på FreeBSD 4.x-system.
linux-i386-system:
    Hostad version för Linux/i386. Det här är den mest
    kompletta och mogna versionen, vilket menas att du kan
    köra alla inkluderade program och demon med den. Det här
    arkivet innehåller alla AROS system binaries kompilerade från
    subversions-trädet.
mingw32-x86_64-system:
    Hostad version för Microsoft Windows på x86_64-plattformen.
mingw32-i386-system:
    Hostad version för Microsoft Windows på i386-plattformen.
    Utvecklad och kompilerad under Windows XP, men bör fungera på
    alla 32-bitars Windows-versioner från och med Windows 98.
linux-x86_64-system:
    Hostad version för Linux/x86_64. Det här är den mest
    kompletta och mogna versionen, vilket menas att du kan
    köra alla inkluderade program och demon med den. Det här
    arkivet innehåller alla AROS system binaries kompilerade från
    subversions-trädet.
linux-ppc-system:
    Hostad version för Linux/PowerPC. Det här arkivet innehåller alla
    AROS system binaries kompilerade från subversions-trädet.
pc-i386-boot-floppy:
    Native version för i386-baserade PC AT datorer och kompatibla.
    Det här arkivet innehåller en startdiskett-image som du snabbt
    kan skriva till diskett och starta upp AROS med.
pc-i386-boot-iso:
    Native version för i386-baserade PC AT datorer och kompatibla.
    Detta är en bootbar CDROM ISO image, som innehåller alla
    AROS-system och bidragande program.
raspi-aarch64-system:
    Native version för ARMv8-baserade 64-bitars Raspberry Pi-datorer.
    Innehåller alla filer som behövs för att starta från ett
    FAT-formaterat sd-kort.
raspi-aarch64-contrib:
    Detta arkiv innehåller alla bidragande program kompilerade
    för den 64-bitars ARMv8-arkitekturen, för användning med
    RasPi/aarch64-portningen.
raspi-aarch64-ports:
    Detta arkiv innehåller applikationer och spel som byggts från
    externa källor för den 64-bitars ARMv8-arkitekturen (både hostad
    och native). På grund av sin storlek kommer arkivet endast att
    uppdateras då och då på snapshots-sidan.
raspi-armhf-system:
    Native version för ARMv6-baserade Raspberry Pi-datorer.
    Innehåller alla filer som behövs för att starta från ett
    FAT-formaterat sd-kort.
raspi-armhf-contrib:
    Detta arkiv innehåller alla bidragande program kompilerade
    för ARM-arkitekturen, för användning med RasPi/ARM-portningen
    (med hard-float ABI). Notera att denna version kräver minst
    en ARMv6-processor med VFP-enhet.
raspi-armhf-ports:
    Detta arkiv innehåller applikationer och spel som byggts från
    externa källor för armhf-arkitekturen (både hostad och native).
    På grund av sin storlek kommer arkivet endast att uppdateras
    då och då på snapshots-sidan.
opensbi-riscv-system:
    Native version för 32-bitars RISC-V-baserade UEFI OpenSBI-system,
    inriktad på applikationsprofilen RVA22. Notera att denna version
    kräver Zifencei-tillägget.
    För närvarande stöds endast Milk-V Titan.
opensbi-riscv-contrib:
    Detta arkiv innehåller alla bidragande program kompilerade
    för 32-bitars RISC-V-arkitekturen (RVA22-profilen), för
    användning med OpenSBI/riscv-portningen.
opensbi-riscv64-system:

    kräver Zifencei-tillägget.
    För närvarande stöds endast Milk-V Titan.
opensbi-riscv64-contrib:
    Detta arkiv innehåller alla bidragande program kompilerade
    för 64-bitars RISC-V-arkitekturen (RVA22-profilen), för
    användning med OpenSBI/riscv64-portningen.
pc-i386-contrib:
    Detta arkiv innehåller alla bidragande program komplierade
    för i386-arkitekturen. Dom fungerar både i (i386-linux)
