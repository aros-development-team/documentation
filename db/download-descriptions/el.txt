ChangeLog-contrib:
    Καταγραφή αλλαγών για τον κώδικα των προγραμμάτων που τρίτοι έχουν συνεισφέρει.
ChangeLog-docs:
    Καταγραφή αλλαγών για την τεκμηρίωση.
source:

contrib-source:
    Κώδικας προγραμμάτων που τρίτοι έχουν συνεισφέρει.
docs-html:
    Τεκμηρίωση σε μορφή HTML. Περιέχει οτιδήποτε είναι διαθέσιμο 
	στην ιστοσελίδα αλλά προσαρμοσμένο για offline διάβασμα.
freebsd5-i386-system:
    Η hosted έκδοση για FreeBSD/i386 5.x. Σημειώστε ότι δε θα
    λειτουργήσει σε FreeBSD 4.x συστήματα.
freebsd-i386-system:
    Η hosted έκδοση για FreeBSD/i386 5.x. Σημειώστε ότι δε θα
    λειτουργήσει σε FreeBSD 4.x συστήματα.
linux-i386-system:
    Η hosted έκδοση για Linux/i386. Αυτή είναι η πιο ολοκληρωμένη
    και ώριμη μεταφορά, το οποίο σημαίνει ότι μπορείτε να εκτελέσετε
    όλα τα προγράμματα και τα demos που έχουν συμπεριληφθεί σε αυτή.
    Αυτό το πακέτο περιέχει όλα τα εκτελέσιμα αρχεία συστήματος του AROS 
	που έγιναν compiled στον Subversion server.
mingw32-x86_64-system:
    Η hosted έκδοση για Microsoft Windows στην πλατφόρμα x86_64.
mingw32-i386-system:
    Η hosted έκδοση για Microsoft Windows στην πλατφόρμα i386.
    Αναπτύχθηκε και έγινε compiled σε Windows XP, αλλά θα πρέπει να
    λειτουργεί σε όλες τις 32-bit εκδόσεις των Windows ξεκινώντας
    από τα Windows 98.
linux-x86_64-system:
    Η hosted έκδοση για Linux/x86_64. Αυτή είναι η πιο ολοκληρωμένη
    και ώριμη μεταφορά, το οποίο σημαίνει ότι μπορείτε να εκτελέσετε
    όλα τα προγράμματα και τα demos που έχουν συμπεριληφθεί σε αυτή.
    Αυτό το πακέτο περιέχει όλα τα εκτελέσιμα αρχεία συστήματος του AROS 
	που έγιναν compiled στον Subversion server.
linux-ppc-system:
    Η hosted έκδοση για Linux/PowerPC. Αυτό το πακέτο περιέχει όλα
	τα εκτελέσιμα αρχεία συστήματος του AROS που έγιναν compiled 
	στον Subversion server.
pc-i386-boot-floppy:
    Η native έκδοση για i386-based PC AT υπολογιστές και συμβατούς.
    Αυτό το πακέτο περιέχει την εικόνα μιας δισκέτας εκκίνησης
    την οποία μπορείτε γρήγορα να γράψετε και να εκκινήσετε το
    AROS με αυτήν.
pc-i386-boot-iso:
    Η native έκδοση για i386-based PC AT υπολογιστές και συμβατούς.
    Αυτή είναι μια ISO εικόνα ενός CDROM εκκίνησης, το οποίο περιέχει
    όλα τα προγράμματα που τρίτοι έχουν συνεισφέρει και το σύστημα AROS.
pc-x86_64-boot-iso:
    Η native έκδοση για 64-bit (x86_64, amd64) υπολογιστές.
    Αυτή είναι μια ISO εικόνα ενός CDROM εκκίνησης, το οποίο περιέχει
    όλα τα προγράμματα που τρίτοι έχουν συνεισφέρει και το σύστημα AROS.
pc-x86_64-smp-boot-iso:
    Αυτή είναι μια εξαιρετικά πειραματική SMP έκδοση για pc-x86_64.
    Συνιστάται μόνο για προγραμματιστές. Αυτή είναι μια ISO εικόνα
    ενός CD-ROM εκκίνησης.
raspi-aarch64-system:
    Η native έκδοση για 64bit υπολογιστές Raspberry Pi βασισμένους
    σε ARMv8. Περιέχει όλα τα αρχεία που χρειάζονται για εκκίνηση
    από μια κάρτα sd διαμορφωμένη σε FAT.
raspi-aarch64-contrib:
    Αυτό το πακέτο περιέχει όλα τα προγράμματα που τρίτοι έχουν
    συνεισφέρει και έγιναν compiled για την 64bit αρχιτεκτονική
    ARMv8, για χρήση με τη μεταφορά RasPi/aarch64.
raspi-aarch64-ports:
    Αυτό το πακέτο περιέχει εφαρμογές και παιχνίδια που κατασκευάζονται
    από εξωτερικές πηγές για την 64bit αρχιτεκτονική ARMv8 (τόσο hosted
    όσο και native). Λόγω του μεγέθους του, το πακέτο θα ενημερώνεται
    μόνο κατά καιρούς στη σελίδα των snapshots.
raspi-armhf-system:
    Η native έκδοση για υπολογιστές Raspberry Pi βασισμένους σε ARMv6.
    Περιέχει όλα τα αρχεία που χρειάζονται για εκκίνηση από μια
    κάρτα sd διαμορφωμένη σε FAT.
raspi-armhf-contrib:
    Αυτό το πακέτο περιέχει όλα τα προγράμματα που τρίτοι έχουν
    συνεισφέρει και έγιναν compiled για την αρχιτεκτονική ARM,
    για χρήση με τη μεταφορά RasPi/ARM (με hard-float ABI).
    Σημειώστε ότι αυτή η έκδοση απαιτεί τουλάχιστον επεξεργαστή
    ARMv6 με μονάδα VFP.
raspi-armhf-ports:
    Αυτό το πακέτο περιέχει εφαρμογές και παιχνίδια που κατασκευάζονται
    από εξωτερικές πηγές για την αρχιτεκτονική armhf (τόσο hosted όσο
    και native). Λόγω του μεγέθους του, το πακέτο θα ενημερώνεται μόνο
    κατά καιρούς στη σελίδα των snapshots.
opensbi-riscv-system:
    Η native έκδοση για 32-bit συστήματα RISC-V με UEFI OpenSBI,
    στοχεύοντας το προφίλ εφαρμογών RVA22. Σημειώστε ότι αυτή η
    έκδοση απαιτεί την επέκταση Zifencei.
    Προς το παρόν υποστηρίζεται μόνο το Milk-V Titan.
opensbi-riscv-contrib:
    Αυτό το πακέτο περιέχει όλα τα προγράμματα που τρίτοι έχουν
    συνεισφέρει και έγιναν compiled για την 32-bit αρχιτεκτονική
    RISC-V (προφίλ RVA22), για χρήση με τη μεταφορά OpenSBI/riscv.
opensbi-riscv64-system:

    έκδοση απαιτεί την επέκταση Zifencei.

opensbi-riscv64-contrib:

    RISC-V (προφίλ RVA22), για χρήση με τη μεταφορά OpenSBI/riscv64.
pc-i386-contrib:
    Αυτό το πακέτο περιέχει όλα τα προγράμματα που τρίτοι έχουν
	συνεισφέρει και έγιναν compiled για i386 αρχιτεκτονική. Θα 
    λειτουργούν στις κατάλληλες hosted (eg. i386-linux) και native
    (i386-pc) εκδόσεις.
pc-x86_64-contrib:
    Αυτό το πακέτο περιέχει όλα τα προγράμματα που τρίτοι έχουν
	συνεισφέρει και έγιναν compiled για x64_86 αρχιτεκτονική, 
	για χρήση με την x86_64 native έκδοση.
linux-ppc-contrib:
    Αυτό το πακέτο περιέχει όλα τα προγράμματα που τρίτοι έχουν
	συνεισφέρει και έγιναν compiled για PowerPC αρχιτεκτονική, 
	για χρήση με την Linux/PowerPC μεταφορά.
