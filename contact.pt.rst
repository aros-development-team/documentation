Lista de eCorreio
=================

Existe um conjunto de listas de eCorreio relacionadas com o AROS,
principalmente para quem prefere receber informação desta forma:

+ `Desenvolvidores AROS`__

  Esta é a lista de eCorreio dos desenvolvidores, onde decorrem as discussões
  sobre o desenvolvimento do AROS. É **altamente** recomendável aos
  desenvolvidores inscreverem-se nesta lista, pois de outro modo será bastante
  difícil manterem-se actualizados sobre os desenvolvimentos em curso. Como não
  há *assim tantos* desenvolvidores AROS, o volume nesta lista é geralmente
  bastante baixo, mas pode tornar-se bastante alto durante discussões acesas.

  .. Note:: A subscrição para esta lista não é assegurada automáticamente,
            mas todo o requerimento é verificado pelo administrador da lista.
            Poderá então ocorrer um atraso desde o tempo do requerimento de
            subscrição até se tornar um membro.


+ `Sistema de Versões Concorrentes (CVS) AROS`__

  Esta é uma lista de eCorreio só de leitura para desenvolvidores, para a qual
  são automaticamente enviados registos sempre que algo é depositado (commit)
  nos repositórios do AROS. Se quiser acompanhar quase em tempo real a
  actividade de depósitos nos repositórios do AROS, esta é a lista para si. O
  volume de tráfego nesta lista pode ser muito alto.

+ `Portal AROS`__

  O guião de construção do portal envia eCorrespondência para esta lista, para
  que os desenvolvidores envolvidos no seu funcionamento e manutenção possam
  resolver os problemas quando surgirem.

Siga as ligações para as páginas administrativas para obter informação em como
subscrever, desistir de subscrição, acesso a arquivos e outras funções úteis.
