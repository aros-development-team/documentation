Списки рассылки
===============

Существует несколько списков рассылки, связанных с AROS, в основном для тех,
кто предпочитает получать информацию таким способом:

+ `AROS Developer`__

  Это список рассылки для разработчиков, в котором обсуждается разработка
  AROS. Разработчикам **настоятельно** рекомендуется подписаться на этот
  список, так как иначе будет довольно сложно следить за текущим ходом
  разработки. Поскольку разработчиков AROS не *так уж* много, объём сообщений
  в этом списке обычно невелик, но во время жарких дискуссий он может
  значительно возрасти.

  .. Note:: Запросы на подписку на этот список не обрабатываются автоматически:
            каждый запрос проверяется администратором списка. Поэтому между
            отправкой запроса на подписку и фактическим вступлением в список
            может пройти некоторое время.


+ `AROS CVS`__

  Это список рассылки для разработчиков, доступный только для чтения, в
  который автоматически отправляются журналы при каждом коммите в репозитории
  AROS. Если вы хотите получать сведения о коммитах в репозитории AROS
  практически в реальном времени, этот список для вас. Объём сообщений в этом
  списке может быть очень большим.

+ `AROS Website`__

  Сценарий сборки веб-сайта отправляет письма в этот список, чтобы
  разработчики, занимающиеся его работой и сопровождением, могли устранять
  проблемы по мере их возникновения.

Перейдите по ссылкам на административные страницы, чтобы узнать, как
подписаться, отписаться, получить доступ к архивам и воспользоваться другими
полезными функциями.
